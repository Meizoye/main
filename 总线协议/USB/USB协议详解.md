# USB协议详解

## 1 核心概念

### 1.1 USB协议概述

USB（Universal Serial Bus，通用串行总线）是由Intel、Microsoft等公司在1996年推出的外部总线标准，旨在简化PC外设连接。

核心特点：

1. 即插即用：自动识别设备，无需手动配置
2. 热插拔：无需关机即可插拔设备
3. 统一接口：一种接口连接多种设备
4. 供电能力：提供5V电源（USB 2.0最大500mA，USB 3.0最大900mA）
5. 高速传输：USB 3.2 Gen 2x2最高20Gbps

### 1.2 USB版本对比

| 版本          | 发布年份 | 最大速率 | 功率 | 典型应用        |
| ------------- | -------- | -------- | ---- | --------------- |
| USB 1.0       | 1996     | 1.5Mbps  | 2.5W | 键盘、鼠标      |
| USB 1.1       | 1998     | 12Mbps   | 2.5W | 音频设备        |
| USB 2.0       | 2000     | 480Mbps  | 2.5W | U盘、打印机     |
| USB 3.0       | 2008     | 5Gbps    | 4.5W | 移动硬盘        |
| USB 3.1 Gen 2 | 2013     | 10Gbps   | 100W | 显示器、SSD     |
| USB 3.2       | 2017     | 20Gbps   | 100W | 高速存储        |
| USB4          | 2019     | 40Gbps   | 240W | Thunderbolt兼容 |

## 2 物理协议

### 2.1 USB 2.0引脚定义

| Pin  | 名称 | 功能    |
| ---- | ---- | ------- |
| 1    | VBus | +5V电源 |
| 2    | D-   | 数据负  |
| 3    | D+   | 数据正  |
| 4    | GND  | 地线    |

### 2.2 **USB 3.0引脚定义**（增加）

- 5个超高速差分对（TX+/TX-、RX+/RX-）
- 向后兼容USB 2.0

### 2.3 USB信号编码

USB2.0以下信号采用反向不归零编码（No-Return-No-Zero Invented) ，信号翻转时为0，不翻转时信号为1，这里将与常规编码做对比。

NO NRZI

```
		0   1   0    0   0    1    0   1
		   ----              ----      ----
----------|    |------------|    |----|   
```

### 2.4 USB字节序

LSB在前，MSB在后

## 3 枚举过程

### 3.1 USB热插拔检测

当有低速设备插入时D-存在上拉电阻使得D-出现高电平识别为低速模式

当有全速设备插入时D+存在上拉电阻使得D+出现高电平识别为全速模式

当有高速设备插入时D+存在上拉电阻使得D+出现高电平识别为全速模式，再通过Chirp序列总线握手机制识别为高速设备

### 3.2 设备枚举

设备插入检测VBus电流变化并识别设备速度

Host复位设备拉低D+/D-至少10ms

Host向0地址发送GET_DESCRIPTIONER请求获取设备描述符，读取设备描述符前8字节，等待设备响应

Host向0地址发送SET_ADDRESS请求重新分配地址，设备地址更新为新地址

Host向新地址发送获取完整设备描述符请求和完整配置描述符请求，识别设备功能

Host向新地址发送SET_CONFIGURATION请求，设备进入配置状态，使能Port和Endpoint，此时可以进行传输
